ENG3103: Project Management Cheatsheet

CH 1: Modern Project Management

  • Project: Temporary endeavor, defined start/end, unique deliverable, constrained by scope, time, budget, quality.
  • Socio-Technical Dimension:
    • Technical (Science): Scope, WBS, Schedules, Resource Allocation, Budgets, Status Reports.
    • Sociocultural (Art): Leadership, Teamwork, Negotiation, Politics, Expectations.
  • Governance: Centralized management ensuring projects align with strategy and resources.

CH 2: Strategy & Selection

  • Strategic Alignment: Projects execute organizational strategy. Selection must eliminate waste.
  • Financial Models:
    • Payback Pd: Est. Cost / Annual Net Inflow
    • NPV: I₀ + Σ [ Ft / (1 + k)t ]
  • Multi-Weighted Scoring: Combines weighted strategic/technical criteria: Σ (Weight × Rating)

CH 3: Structure & Culture

  • Functional: Standard hierarchy; PM has low authority.
  • Dedicated: Self-contained; PM has full authority.
  • Matrix: Dual authority (Functional Mgr + PM).
    • Weak: Functional mgr dominates.
    • Balanced: PM defines what, Func defines how.
    • Strong: PM controls decisions, Func provides staff.

CH 4: Defining the Project

  • Scope Statement: Objectives, deliverables, milestones, technical specs, boundaries, exclusions.
  • Priority Matrix: Balance Cost, Time, Performance across Constrain (fixed), Enhance (optimize), Accept.
  • WBS: Hierarchical map breaking project into Work Packages (lowest level).
  • OBS: Integrates WPs with org units (Cost Accounts).
  • RACI: Responsible, Accountable, Consulted, Informed.

CH 5: Estimating Times & Costs

  • Top-Down (Macro): Early/strategic (Delphi, Ratio, Apportionment). Fast but less accurate.
  • Bottom-Up (Micro): WBS roll-up. Highly accurate, used for fixed-price bidding.
  • Cost Types:
    • Direct: Labor, materials, equipment.
    • Direct Overhead: PM salary, temporary facilities.
    • G&A Overhead: Corporate indirect costs.

CH 6: Project Network & Time

  • Forward Pass (Early):
    ES = max(EF of predecessors)
    EF = ES + Duration
  • Backward Pass (Late):
    LF = min(LS of successors)
    LS = LF - Duration
  • Slack / Float:
    • Total Slack (TS): Max delay without delaying project. TS = LS - ES = LF - EF
    • Free Slack (FS): Max delay without delaying any successor. FS = min(ESsucc) - EF
  • Critical Path: Longest path; shortest duration; all activities have TS = 0.

CH 8: Scheduling Resources & Costs

  • Constraints: Technical (logic/sequence) vs Resource.
  • Time-Constrained: Fixed end-date. Use Smoothing (delay non-critical tasks within TS to level peaks).
  • Resource-Constrained: Fixed resources. Use Leveling (delays tasks, usually extends duration).
  • Priority Heuristics (Leveling): 1. Min Slack, 2. Smallest Duration, 3. Lowest ID.
  • Time-Phased Budget: Distributes budget over schedule for EVM.

CH 9: Reducing Project Duration

  • Compression Options:
    • Unlimited Res: Crashing (overtime), Outsourcing.
    • Constrained Res: Fast-tracking (SS lags), reduce scope.
  • Crashing Steps:
    1. Find Critical Path(s).
    2. Calculate Cost Slope for activities.
    3. Crash critical activity with lowest Cost Slope.
    4. Check for new critical paths. Stop when target met.
    • Slope = (Crash Cost - Normal Cost) / (Normal Time - Crash Time)
